# Yier AI questionnnaire system

## 一个基于 React + TypeScript 的在线问卷系统。

## 技术栈

- React 18
- TypeScript
- Redux Toolkit
- React Router v6
- Ant Design 5.x
- SASS
- dnd-kit (拖拽功能)
- recharts (图表功能)
- axios

## 功能特性

- 问卷编辑
  - 多种题型支持
  - 拖拽排序
  - 编辑撤销/重做
  - 问卷模板
- 问卷发布
  - 问卷链接分享
  - 二维码分享
- 数据统计
  - 答卷数据实时统计
  - 图表可视化展示
- 个人中心
  - 问卷管理
  - 回收站

## 开始使用

### 环境要求

- Node.js >= 16
- npm >= 7

### 安装依赖

- npm install
